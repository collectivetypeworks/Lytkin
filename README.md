# Lytkin

Lytkin is a typeface designed by Danilo Borovinić and Antonina Samokhina and published by Collective Typeworks.

The typeface supports Latin, Cyrillic, and Old Permic scripts, including extended Cyrillic characters used for Komi languages and extended Latin characters for historical Komi orthographies.

Lytkin is available as a variable font with a Weight (`wght`) axis and as five static styles:

* ExtraLight
* Light
* Regular
* SemiBold
* Bold
