# Lytkin

Lytkin is a contemporary sans serif typeface designed for text, distinguished by its comprehensive support for the Old Permic script and for most historical orthographies of the Komi languages based on Cyrillic and Latin scripts.

The typeface was created as a non-commercial initiative to support and contribute to the cultural development of communities in the Komi Republic and Perm Krai. Lytkin is intended for linguists, designers, typographers, and language activists who need a contemporary typographic tool for working with the Old Permic script and the written heritage of the Komi languages.

The primary sources for the development of the Old Permic characters were the scholarly works of linguist Vasily Lytkin, particularly his comparative tables documenting the various historical forms of each character. The design process was also informed by consultations with members of the language community, including users and advocates of the Old Permic script.

Lytkin was designed by Danilo Borovinić and Antonina Samokhina as part of Collective Typeworks.

## Scripts

Lytkin supports Latin, Cyrillic, and Old Permic scripts, including extended Cyrillic characters used for Komi languages and extended Latin characters used in historical Komi orthographies.

## Styles

Lytkin is available as a variable font with a Weight (`wght`) axis and as five static styles:

- ExtraLight
- Light
- Regular
- SemiBold
- Bold

## Building

The fonts can be built from the source using `gftools`:

```sh
gftools builder sources/config.yaml
```

The required Python packages and versions are listed in `requirements.txt`.
